This github site summarizes all files for a python course for physicists. 
The course is currently held in person, but a YouTube version might follow in the future. 
The starts at the fundamentals and introduces topics relevant to physicists (numpy and matplotlib). 
No prior physics knowledge is needed for this course, however a lot of tasks are physics related. 

The course is made up by 18 "chunks". Each chunk contains the following: 
- Lecture Slides (~15 minutes of content) (PDF)
- Cheat Sheet (PDF)
- Task Sheet, with basic and advanced tasks (Jupyter Notebook)

Besides that, there is a single cheat sheets sumarizing all contents. 

The topics of the chunks are the following:
1. Introduction
2. Setup
3. Variables
4. Logic Operators
5. Lists, Dictionaries and Sets
6. Loops
7. Lists in Loops
8. Functions
9. Imports
10. Numpy Introduction
11. Mutable and Non-Mutable variables (tbd.)
12. Reading and Writing Files
13. Matplotlib
14. Numpy (2D / nD)
15. 2D Matplotlib
16. Advanced Matplotlib
17. Advanced Numpy
18. Scipy, Linear Regression and Polyfit

The following topics might be added as optional extra chuncks (tbd.)
- Version control and git

- Typing / Pretty Coding / PEP
- Multithreading / -processing
- Object Oriented Programming
